### 4. **NEW: `calculateGSTFromInclusive(inclusivePrice)`** - ADD THIS
**Purpose:** Central GST calculation function
**Location:** Add near line ~1300 (before updateCalculations)

```javascript
function calculateGSTFromInclusive(inclusivePrice, gstRate = 18) {
    const basePrice = inclusivePrice / (1 + gstRate / 100);
    const totalGst = inclusivePrice - basePrice;
    const sgst = totalGst / 2;
    const cgst = totalGst / 2;
    
    return {
        inclusivePrice: Math.round(inclusivePrice),
        basePrice: Math.round(basePrice),
        sgst: Math.round(sgst),
        cgst: Math.round(cgst),
        totalGst: Math.round(totalGst)
    };
}
```
