remaining_sessions = total_package_sessions - used_sessions

Package total = 4 sessions

Remaining = 4 - 3 = 1

1 / 4 sessions

If invoice already had:

Qty = 2 (already deducted)

And user changes it to:

Qty = 3

System must:

Step 1: Restore old quantity back to package
Step 2: Deduct new quantity
Step 3: Recalculate remaining sessions
Step 4: Update UI immediately

3️⃣ Real-Time UI Update Required

When Qty changes

When invoice loads in edit mode

When service is removed

When invoice is saved

The following must refresh:

Active package balance

Progress bar

Billing summary

Fix the quantity change handler (handleQtyChange or similar)

Fix edit invoice logic so it:

Restores old usage before applying new usage

Recalculates package usage properly

Ensure state is updated correctly (React state / Vue reactive / etc.)

Ensure no double deduction happens

Ensure package usage is tied to invoice ID
